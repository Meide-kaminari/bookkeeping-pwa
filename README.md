# iPhone 记账器（PWA）

这是可安装到 iPhone 主屏幕的离线网页 App，不需要 App Store、IPA 或 Apple 签名。它使用浏览器的 IndexedDB 保存数据；每次保存账目后会立即写入本机。

## 部署

将此文件夹中的所有文件部署到任意 **HTTPS** 静态网站空间，例如 GitHub Pages、Cloudflare Pages 或 Netlify。根地址必须直接对应本文件夹，且不要改变文件名。

## 在 iPhone 安装

1. 用 Safari 打开部署后的 HTTPS 地址。
2. 点击 Safari 的“分享”按钮，选择“添加到主屏幕”。
3. 点击“添加”。之后从主屏幕打开“记账器”，可离线使用。

## 数据安全

账目不上传到服务器，保存在当前 iPhone/Safari 的本地数据库。请定期点击“导出备份”，并把 JSON 备份保存到“文件”或网盘。导入备份会合并同编号账目。

> 清除 Safari 网站数据、换手机或换浏览器会失去该浏览器中的本地账目；先导出备份即可避免丢失。
